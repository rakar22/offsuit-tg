# Offsuit TG

Hold'em estilo Offsuit para Telegram Mini App.

## Modos
- Practicar vs IA (local)
- Mesa privada con jugadores reales (P2P, el anfitrion aloja la partida)
- Rellenar sillas vacias con IA

## Telegram
1. Despliega esta carpeta en HTTPS (Vercel / GitHub Pages).
2. @BotFather → /newbot → /newapp
3. Web App URL = la URL publica
4. En index.html pon `window.OFFSUIT_BOT = 'TuBot';` (sin @)
5. Abre el bot y lanza la Mini App

Invitar: codigo de sala o `https://t.me/TuBot/app?startapp=CODIGO`
